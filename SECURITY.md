# Security

If you find a security problem in a Zij repository or on zij.watch, report it privately by email to [info@zij.watch](mailto:info@zij.watch). Do not open an issue, a pull request or a discussion about it: those are public.

Say what you found, where, and the steps to reproduce it. We will reply, tell you what we will do about it, and tell you when it is fixed.

## What to report

- A secret committed to a repository, such as an API key or the FIRMS `MAP_KEY`.
- A way to read or change data you should not reach, on zij.watch or in the app.
- A vulnerable dependency that the app actually uses.

## Supported versions

Only the latest commit on `main` of each repository, and the site as it is served at zij.watch.
